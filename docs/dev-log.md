# RingsVision

Computer vision tool for analysing Gymnastics Still Rings technique from training images and footage.

## Status

RingsVision is currently in early development. The project can load and validate a static image, inspect its NumPy dimensions, convert it from OpenCV's BGR colour order to RGB, and display it successfully.

## Planned MVP

The initial MVP will analyse a prerecorded Iron Cross video using pose estimation, joint-angle measurements, hold detection and interpretable rule-based feedback.

## Technologies

- Python
- OpenCV
- NumPy
- MediaPipe (planned)

# RingsVision

Computer vision tool for analysing Still Rings technique from training footage.

## Status

Early development. The initial OpenCV image-loading pipeline is complete, with MediaPipe static pose detection working

## Planned MVP

Analyse prerecorded Iron Cross footage using pose estimation, joint-angle measurements, hold detection and interpretable rule-based feedback

## Technologies

- Python
- OpenCV
- NumPy
- MediaPipe (planned)
